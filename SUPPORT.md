# QBCore FiveM support

GitHub issues are for reproducible defects, feature proposals, and documentation
problems in official QBCore resources. They are not a general installation or
server-configuration help desk.

## Before asking for help

1. Read the [official QBCore documentation](https://docs.qbcore.org).
2. Search the affected repository's open and closed issues.
3. Test with current official resources and compatible dependencies.
4. Reduce the problem to the smallest reproducible example.

For installation, configuration, migration, and usage questions, use the
[official QBCore Discord](https://discord.gg/qbcore).

When requesting help, include the affected resource, exact versions or commits,
FXServer artifact, server operating system, reproduction steps, and a short
redacted console excerpt. Explain any modifications to official resources.

Do not publish passwords, tokens, webhook URLs, license keys, database
credentials, player identifiers, private server data, or security vulnerability
details. Follow the [security policy](SECURITY.md) and report vulnerabilities
privately through the affected repository's **Security** tab.
