# QBCore FiveM

**QBCore FiveM** is an open-source framework ecosystem for [FiveM](https://fivem.net/), the multiplayer modification platform for Grand Theft Auto V. It provides a modular foundation for building feature-rich roleplay servers.

## 🚀 What We Build

- **Core framework** — A modular foundation for server and player systems
- **Gameplay resources** — Jobs, housing, vehicles, inventory, economy, and utilities
- **Developer tooling** — Shared libraries, integrations, and community tools

Visit the [QBCore documentation](https://docs.qbcore.org) for installation, configuration, and development guides.
